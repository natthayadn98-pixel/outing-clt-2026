# การเข้าสู่ระบบ Admin ด้วย Username

เปิด admin.html แล้วกรอก Username และรหัสผ่าน Supabase Auth เดิม

- AdminIT1 → clt.admin01@yourcompany.com
- AdminIT2 → clt.admin02@yourcompany.com
- AdminIT3 → clt.admin03@yourcompany.com

ระบบรองรับชื่อผู้ใช้โดยไม่สนตัวพิมพ์เล็ก/ใหญ่ และไม่อนุญาตอีเมลในช่อง Username

**ความปลอดภัย:** การแปลงชื่อผู้ใช้เป็นอีเมลเป็นเพียงความสะดวกด้าน UI ไม่ใช่การให้สิทธิ์ Admin; ระบบยังตรวจสอบรหัสผ่านผ่าน Supabase Auth และตรวจสอบสิทธิ์กับ Edge Function secure-checkin (`check_admin`) เช่นเดิม

โปรดตรวจสอบว่าบัญชีอีเมลทั้งสามมีอยู่จริงใน Supabase Auth และได้รับสิทธิ์ Admin จากระบบเดิม ไม่ต้องเปลี่ยนรหัสผ่านหรือสร้างบัญชีใหม่

ไฟล์นี้แก้จาก ZIP ที่อัปโหลดในแชตครั้งนี้เท่านั้น ไม่ได้รวมการแก้ไขอื่นจาก ZIP เวอร์ชันก่อนหน้า หากมีการปรับหน้า Cloud เพิ่มเติมภายหลัง ต้องรวมการเปลี่ยนแปลงจากทั้งสองเวอร์ชันก่อนเผยแพร่
