CLT 2569 — อัปเดตฟอนต์ทั้งเว็บไซต์

ฟอนต์ Google Fonts: Mali + Sarabun ตามลิงก์ที่กำหนด
- Mali สำหรับหัวข้อหลักและหัวข้อรอง (h1–h6)
- Sarabun สำหรับคำอธิบาย ปุ่ม ตาราง ตัวเลข ช่องกรอกข้อมูลและข้อความอื่น ๆ
- หน้าเว็บ HTML ทั้ง 11 หน้าใช้ clt-fonts.css ร่วมกัน
- คงการเชื่อมต่อ Supabase, QR, LINE LIFF และการทำงานเดิมไว้

การติดตั้ง
1. สำรองไฟล์บน GitHub ปัจจุบันก่อน
2. อัปโหลดไฟล์ HTML ทั้ง 11 หน้า และ clt-fonts.css จากชุด ZIP ไปโฟลเดอร์เดียวกันใน GitHub
3. เก็บไฟล์รูป PNG และ admin-pages-theme.css ที่มีใน ZIP ไปพร้อมกันถ้าบน GitHub ยังไม่มี
4. กด Commit changes แล้วทดสอบแบบรีเฟรชใหม่ (Ctrl+F5 บนคอม หรือปิด/เปิดหน้า LIFF บนมือถือ)
5. ฟอนต์ใหม่ต้องต่ออินเทอร์เน็ตเพื่อดาวน์โหลดจาก Google Fonts; เมื่อโหลดไม่ได้จะใช้ฟอนต์สำรอง

ข้อควรทราบ: ZIP นี้อิงไฟล์ RAR ที่ส่งมาในบทสนทนาครั้งนี้ หากเว็บจริงมีการแก้หลังจากสร้าง RAR อย่าอัปโหลดทับโดยไม่เปรียบเทียบ

ไม่ต้องแก้ SQL หรือ Edge Functions เพราะเป็นการเปลี่ยนฟอนต์หน้าเว็บเท่านั้น
